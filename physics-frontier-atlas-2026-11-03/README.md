# 物理前沿：20张博士研究图谱

面向物理博士和研究者的精选版图，不是对物理学“所有知识点”的穷尽目录。覆盖粒子物理、引力与量子引力、宇宙学、QCD、弦论/SUSY/GUT、数学物理、量子物质、超导、非平衡量子系统及等离子体聚变。

每张图包括概念关系图、方程及其限定、六个研究切面、证据边界和来源编号。资料检索截止2026-11-03。图中标注“开放/候选/模型依赖”的议题不是已确立事实。近期结果以实验合作组、PDG和论文原文为准。箭头是知识关系的简化编排，不表示唯一因果或必然研究次序。阅读时请打开图下的来源索引查看原文及具体限定。

高清PNG和矢量SVG均为3600×2700画布；HTML可逐图查看与追溯来源。运行 `python build.py` 可重建全部文件；需要项目 `olympiad-pdf` 环境中的 Pillow、Noto CJK 字体和 rsvg-convert。
